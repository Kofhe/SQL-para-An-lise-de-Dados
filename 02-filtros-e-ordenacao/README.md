> 🧠 **Avançando nos estudos de SQL: filtrando e encontrando informações específicas em uma base de dados hospitalar.**

Nesta segunda etapa, o objetivo foi aprender a utilizar condições para **filtrar registros** de acordo com determinados critérios.

Depois de conhecer a estrutura e os dados disponíveis na primeira etapa, comecei a trabalhar com perguntas mais específicas, buscando informações que atendam a determinadas condições. 🔍

## 🎯 Objetivo da etapa

Nesta etapa, pratiquei consultas para:

* 🔎 Filtrar registros de acordo com uma condição
* 🏥 Encontrar atendimentos de uma unidade específica
* 👥 Filtrar pacientes de acordo com a idade
* 🚨 Identificar atendimentos por nível de prioridade
* 📋 Selecionar apenas as colunas necessárias
* 🔢 Contar registros que atendem a determinado critério
* 🧠 Transformar perguntas específicas em consultas SQL

---

# 🧩 Desafios

## 🏥 Desafio 01 — Filtrando por unidade

**Pergunta:**

> Quais atendimentos pertencem ao Hospital Centro?

### 💡 O que estou praticando?

Utilizei uma condição para localizar registros relacionados a uma unidade hospitalar específica.

O exercício também permitiu praticar a utilização do **`LIKE`** para realizar uma busca por texto.

---

## 👵 Desafio 02 — Filtrando por idade

**Pergunta:**

> Quais atendimentos são de pacientes com idade maior que 60 anos?

### 💡 O que estou praticando?

Neste desafio, utilizei um operador de comparação para filtrar os registros de acordo com a idade dos pacientes.

---

## 🚨 Desafio 03 — Filtrando por prioridade

**Pergunta:**

> Quais atendimentos possuem prioridade "Urgente"?

### 💡 O que estou praticando?

Aqui o objetivo foi filtrar registros com base em um valor específico de uma coluna.

Esse tipo de filtro pode ser utilizado para localizar rapidamente determinados tipos de atendimento dentro de uma base.

---

## 📋 Desafio 04 — Selecionando informações específicas

**Pergunta:**

> Quais são o ID do atendimento, a especialidade, a idade e o status dos pacientes com idade entre 30 e 50 anos?

### 💡 O que estou praticando?

Além de filtrar os registros por idade, pratiquei a seleção de **apenas as colunas necessárias** para responder à pergunta.

Também utilizei o **`BETWEEN`** para trabalhar com um intervalo de valores.

---

## 🔢 Desafio 05 — Contando registros filtrados

**Pergunta:**

> Quantos atendimentos possuem status "Finalizado"?

### 💡 O que estou praticando?

Neste desafio, combinei um filtro com a função **`COUNT()`** para descobrir a quantidade de registros que atendem a uma determinada condição.

---

# 📚 O que aprendi?

Nesta etapa, comecei a trabalhar com consultas mais direcionadas, utilizando filtros para encontrar informações específicas dentro da base de dados.

### 🧠 Principais conceitos

| 💻 Comando | 🎯 Para que serve                               |
| :--------: | :---------------------------------------------- |
|   `WHERE`  | Filtrar registros de acordo com uma condição    |
|   `LIKE`   | Realizar buscas por padrões de texto            |
|  `BETWEEN` | Filtrar valores dentro de um intervalo          |
|  `COUNT()` | Contar registros                                |
|     `>`    | Comparar valores maiores que determinado número |
|     `=`    | Comparar valores iguais                         |

### 💭 Principal aprendizado

> Depois de conhecer os dados, posso utilizar filtros para **fazer perguntas mais específicas à base e encontrar exatamente as informações que preciso**.

Também comecei a entender que diferentes condições podem ser utilizadas para transformar uma pergunta em uma consulta SQL.
