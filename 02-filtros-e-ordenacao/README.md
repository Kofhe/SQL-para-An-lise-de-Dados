# 🔎 Etapa 02 — Filtros e Ordenação

> 🧠 **Praticando filtros e condições em SQL com uma base de dados hospitalar.**

Nesta etapa, foram realizados exercícios utilizando a cláusula `WHERE` para filtrar informações de acordo com diferentes critérios.

### 🛠️ Conceitos praticados

* `WHERE`
* `LIKE`
* `=`
* `>`
* `BETWEEN`
* `COUNT()`
* Seleção de colunas específicas

### 📋 Exercícios realizados

**1.** Listar atendimentos da unidade **Hospital Centro**.

**2.** Listar atendimentos de pacientes com idade **maior que 60 anos**.

**3.** Listar atendimentos com prioridade **Urgente**.

**4.** Selecionar `id_atendimento`, `especialidade`, `idade` e `status` de pacientes com idade entre **30 e 50 anos**.

**5.** Contar quantos atendimentos possuem status **Finalizado**.

### 💡 O que pratiquei

Nesta etapa, pratiquei a aplicação de filtros em consultas SQL para encontrar informações específicas dentro de uma base de dados. Também trabalhei com condições numéricas, textos, intervalos e funções de agregação.
